CONNECT — SOCIAL/CHAT WEBSITE V1

This is a front-end demo that runs in a browser.

Included:
- Login and signup (demo/local browser storage)
- Mobile-friendly home/feed
- Create posts
- Basic chat interface
- User profile
- Local persistence with localStorage

IMPORTANT:
This version is NOT a real multi-user online service. Login data, posts and chats are stored only in the browser. Do not use real passwords.

To run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Create an account and test the site.

For a real website, the next step is to connect authentication, database, real-time messaging, image uploads, moderation and secure server-side rules (for example using Firebase or another backend).
